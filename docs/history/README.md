## 使用边界

- 历史计数、运行编号、路径和“尚未验证”结论均按原样保留，引用时必须带上日期。
- 证据不得包含配对串、API key、Hook token、attachToken、私有请求正文、完整环境或无关个人窗口。
- 新发现写入当前文档；不要为了制造“已完成”外观而回改历史结论。
